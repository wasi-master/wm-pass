Raivo is discontinued and has no export guide, so these steps follow the app's menus.

<Steps>

1. Open Raivo and unlock it.
2. Go to Raivo's settings and find the **Data** section.
3. Tap **Export OTPs to ZIP archive**.
4. Read the notice, then tap **Export**.
5. Wait a few seconds for the archive to be built.
6. In the share sheet, save the ZIP to Files or send it to the device that runs WM Pass.
7. Unzip it with your Raivo master password and keep the JSON file inside.

</Steps>

## Good to know

- Raivo is discontinued.
- The ZIP is encrypted with your master password (without the passcode). If the password has special characters, some unzip tools fail; Raivo suggests opening the ZIP in the iOS Files app.
- The ZIP holds a JSON file and an HTML file; WM Pass reads the JSON one.

## Then, in WM Pass

Open Settings, Import, and choose the file. The [import steps](/guides/import-export/#importing-into-wm-pass) cover every WM Pass app.

Delete the export once WM Pass has read it.

If you exported on a computer and use WM Pass on your phone, import the file in WM Pass on that computer and [sync](/guides/backup-sync/), or copy the file to the phone over a USB cable. Email and cloud drives keep copies of what passes through them.
