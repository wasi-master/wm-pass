Buttercup has no export guide in its documentation, so these steps follow the desktop app's own menu code.

<Steps>

1. Open Buttercup Desktop and unlock the vault you want to move. Export stays greyed out while the vault is locked.
2. In the menu bar, open **Current Vault**.
3. Choose **Export**.
4. Pick a place, keep the **csv** extension, and save the file.

</Steps>

Steps from [Buttercup Desktop's menu and export code](https://github.com/buttercup/buttercup-desktop/blob/master/source/main/services/export.ts).

</TabItem>
</Tabs>

## Good to know

- The export covers one vault, the one that is current. Repeat for each vault you want to move.
- Buttercup's own importer notes say the same CSV can be brought back into Buttercup Desktop.

## Then, in WM Pass

Open Settings, Import, and choose the file. The [import steps](/guides/import-export/#importing-into-wm-pass) cover every WM Pass app.

Delete the export once WM Pass has read it.

If you exported on a computer and use WM Pass on your phone, import the file in WM Pass on that computer and [sync](/guides/backup-sync/), or copy the file to the phone over a USB cable. Email and cloud drives keep copies of what passes through them.
