<TabItem label="Computer" icon="laptop">

SafeInCloud's own guide names the formats but not the menu. The File, Export path below is the one other apps' import guides give, so it may differ in your version.

<Steps>

1. Open the SafeInCloud desktop app and unlock your database.
2. Open the **File** menu and choose **Export**.
3. Pick **XML** as the format and save the file.

</Steps>

Steps from [Import from SafeInCloud](https://help.enpass.io/personal/latest/all/import-from-safeincloud).

</TabItem>
</Tabs>

## Then, in WM Pass

Open Settings, Import, and choose the file. The [import steps](/guides/import-export/#importing-into-wm-pass) cover every WM Pass app.

Delete the export once WM Pass has read it.

If you exported on a computer and use WM Pass on your phone, import the file in WM Pass on that computer and [sync](/guides/backup-sync/), or copy the file to the phone over a USB cable. Email and cloud drives keep copies of what passes through them.
