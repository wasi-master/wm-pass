<Steps>

1. Open Enpass on your computer and unlock it.
2. In the **File** menu, select **Export**.
3. Choose the vault to export and set the file format to **.json**.

   <Shot src="https://help.enpass.io/__attachments/a_5e3ebc43e246a9f10687ef14300d631fa93c9d812a5c0ca70d768c3dcccea364/image-20260516-103129.png" alt="Enpass Export dialog with the vault set to Primary and the file format set to .json" from="https://help.enpass.io/personal/latest/desktop/importing-from-enpass" publisher="Enpass" />

4. Tick **Include Trashed** or **Include Archived** only if you want those items too.
5. Under **Choose Location**, click the folder icon and pick where to save the file.
6. Click **Continue** to export.

</Steps>

## Good to know

- Passkeys can't be exported from Enpass or imported by other password managers.
- Export one vault at a time. If you keep several Enpass vaults, repeat the export for each.

## Then, in WM Pass

Open Settings, Import, and choose the file. The [import steps](/guides/import-export/#importing-into-wm-pass) cover every WM Pass app.

Delete the export once WM Pass has read it.

If you exported on a computer and use WM Pass on your phone, import the file in WM Pass on that computer and [sync](/guides/backup-sync/), or copy the file to the phone over a USB cable. Email and cloud drives keep copies of what passes through them.
