<Aside type="tip" title="Which file">
Choose **Aegis (.JSON)** with **Encrypt the vault** unticked. WM Pass can't read an encrypted Aegis export.
</Aside>

<Tabs syncKey="device">
<TabItem label="Android" icon="mobile-android">

Aegis has no export guide of its own, so these steps follow the app's menus.

<Steps>

1. Open Aegis and unlock it.
2. Open **Settings**, then **Import & Export**.
3. Tap **Export**.
4. Set the format to **Aegis (.JSON)**.
5. Untick **Encrypt the vault**.
6. Tick **I understand the risk**.
7. Leave **Export all groups** ticked unless you only want some groups.
8. Tap **OK**, then pick where to save the file.

</Steps>

Steps from [Aegis README](https://github.com/beemdevelopment/Aegis/blob/master/README.md).

</TabItem>

## Good to know

- Aegis also offers Text file (.TXT) and Web page (.HTML) exports. Use the .JSON one.
- If you set a separate backup and export password under Security, that applies only to the encrypted export.

## Then, in WM Pass

Open Settings, Import, and choose the file. The [import steps](/guides/import-export/#importing-into-wm-pass) cover every WM Pass app.

Delete the export once WM Pass has read it.
