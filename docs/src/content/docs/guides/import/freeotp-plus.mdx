<TabItem label="Android" icon="mobile-android">

FreeOTP+ has no export guide, so these steps follow the app's menus.

<Steps>

1. Open FreeOTP+.
2. Tap the three-dot menu at the top.
3. Tap **Export**, then **Export JSON format**.
4. Choose where to save the file.

</Steps>

Steps from [FreeOTP+ README](https://github.com/helloworld1/FreeOTPPlus/blob/master/README.md).

</TabItem>

</Aside>

## Good to know

- FreeOTP+ also offers Export key URI format; use the JSON format for WM Pass.

## Then, in WM Pass

Open Settings, Import, and choose the file. The [import steps](/guides/import-export/#importing-into-wm-pass) cover every WM Pass app.

Delete the export once WM Pass has read it.
