<Aside type="tip" title="Which file">
Choose **Export to CSV**. The DASH file is encrypted and WM Pass can't read it. The export is a ZIP of several CSV files; choose the one named credentials.
</Aside>

<TabItem label="Android" icon="mobile-android">
<Steps>

1. In the Dashlane Android app, open the side menu and select **Settings**.

   <Shot src="https://support.dashlane.com/hc/article_attachments/32905397264146" alt="Dashlane Android side menu with Settings highlighted" from="https://support.dashlane.com/hc/en-us/articles/32905278138002-Export-your-Dashlane-data-to-a-CSV" publisher="Dashlane" />

2. Select **General**.

   <Shot src="https://support.dashlane.com/hc/article_attachments/32905409011986" alt="Dashlane Android Settings with General highlighted" from="https://support.dashlane.com/hc/en-us/articles/32905278138002-Export-your-Dashlane-data-to-a-CSV" publisher="Dashlane" />

3. Select **Export data to CSV**.

   <Shot src="https://support.dashlane.com/hc/article_attachments/32905397267218" alt="Dashlane Android General screen with Export data to CSV highlighted" from="https://support.dashlane.com/hc/en-us/articles/32905278138002-Export-your-Dashlane-data-to-a-CSV" publisher="Dashlane" />

4. Select **Export & download**, enter your Master Password in the pop-up, then select **Unlock**.
5. If a message asks you to move personal items out of your Business Space, move them and export again, or select **Continue**.
6. When the message about the Downloads folder appears, select **See file**.
7. Open the **Dashlane CSV** folder in Downloads.

   <Shot src="https://support.dashlane.com/hc/article_attachments/32905397268370" alt="Android Downloads screen with the Dashlane CSV folder highlighted" from="https://support.dashlane.com/hc/en-us/articles/32905278138002-Export-your-Dashlane-data-to-a-CSV" publisher="Dashlane" />

8. Choose **credentials.csv** when WM Pass asks for the file.

   <Shot src="https://support.dashlane.com/hc/article_attachments/32905397268882" alt="Contents of the Dashlane CSV folder with credentials.csv, ids.csv, payments.csv, personalInfo.csv and secureNotes.csv highlighted" from="https://support.dashlane.com/hc/en-us/articles/32905278138002-Export-your-Dashlane-data-to-a-CSV" publisher="Dashlane" />

</Steps>

2. In the Settings panel, select **Export data**.

   <Shot src="https://support.dashlane.com/hc/article_attachments/32905409007250" alt="Dashlane Settings panel with Export data highlighted" from="https://support.dashlane.com/hc/en-us/articles/32905278138002-Export-your-Dashlane-data-to-a-CSV" publisher="Dashlane" />

   <Shot src="https://support.dashlane.com/hc/article_attachments/32905409008146" alt="Dashlane Export data panel with Export to CSV highlighted" from="https://support.dashlane.com/hc/en-us/articles/32905278138002-Export-your-Dashlane-data-to-a-CSV" publisher="Dashlane" />

## Good to know

- The export is several CSV files (credentials, ids, payments, personal info, secure notes, and Wi-Fi on Apple apps). WM Pass reads logins and passwords from the file named credentials.
- Passkeys can't be exported to CSV. They may appear in the file but won't work after import.
- Items shared with you with the Can autofill permission are left out of the credentials file.
- Secure Note attachments aren't exported. Download them separately.
- Authenticator tokens aren't exported directly, but the credentials file has an otpSecret column with the 2FA setup code for logins that use 2FA.
- Only the first line of a note shows when you open the CSV in a spreadsheet, but the file holds the full note.
- On a work plan, the admin may have turned export off. Business Space items may need moving to the Personal Space first.

## Then, in WM Pass

Open Settings, Import, and choose the file. The [import steps](/guides/import-export/#importing-into-wm-pass) cover every WM Pass app.

Delete the export once WM Pass has read it.
