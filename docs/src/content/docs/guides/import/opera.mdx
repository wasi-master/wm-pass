<Aside type="tip" title="Which file">
Opera saves your passwords as a CSV file in the same layout as Google Password Manager (name, url, username, password, note). WM Pass reads it as it reads that one.
</Aside>

<Tabs syncKey="device">
<TabItem label="Android" icon="mobile-android">

<Aside>
The Opera help page that describes the export does not say it exists on Android. Export from Opera on a computer.
</Aside>

</TabItem>
<TabItem label="Computer" icon="laptop">
<Steps>

1. Open Opera and go to **Settings** (Alt + P).
2. Click **Advanced** in the left sidebar, then **Privacy & security**.
3. Under **Autofill**, click **Passwords**.
4. In the Password Manager, click **Settings** in the left sidebar.
5. Next to **Export passwords**, click **Download file**.
6. If asked, confirm with your computer password, then choose where to save the file.

</Steps>

Steps from [Web preferences](https://help.opera.com/en/latest/web-preferences/).

</TabItem>
</Tabs>

## Good to know

- Opera's help strongly recommends deleting the file once you are done, because it holds sensitive information.
- Older Opera versions put the export under **Saved Passwords**, behind a three-dot menu. If you do not see **Download file**, look there.

## Then, in WM Pass

Open Settings, Import, and choose the file. The [import steps](/guides/import-export/#importing-into-wm-pass) cover every WM Pass app.

Delete the export once WM Pass has read it.

If you exported on a computer and use WM Pass on your phone, import the file in WM Pass on that computer and [sync](/guides/backup-sync/), or copy the file to the phone over a USB cable. Email and cloud drives keep copies of what passes through them.
