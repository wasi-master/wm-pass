<Aside type="tip" title="Which file">
Make a **Backup (plain-text)**, which is a JSON file. WM Pass can't read the password-protected or OpenPGP backups.
</Aside>

<Tabs syncKey="device">
<TabItem label="Android" icon="mobile-android">

andOTP is no longer maintained and has no export guide, so these steps follow the app's menus. Your version may look slightly different from the picture.

<Steps>

1. Open andOTP.
2. Tap the three-dot menu, then **Backup**.
3. Under Plain-text backups, tap **Backup (plain-text)**.

   <Shot src="https://raw.githubusercontent.com/andOTP/andOTP/master/assets/screenshots/backup_activity.png" alt="andOTP's Backups screen with Backup (plain-text) at the top" from="https://github.com/andOTP/andOTP" publisher="andOTP (GitHub)" />

4. Read the security warning and tap **Yes**.
5. Choose where to save the JSON file.

</Steps>

## Good to know

- andOTP is archived and no longer maintained.
- Only the backup functions inside andOTP work; backing up the app with a third-party tool loses the data.
- If you have set a default backup location in andOTP settings, the file may be written there instead of asking.

## Then, in WM Pass

Open Settings, Import, and choose the file. The [import steps](/guides/import-export/#importing-into-wm-pass) cover every WM Pass app.

Delete the export once WM Pass has read it.
