LastPass has one plain export, **Export data for use anywhere**, which saves a CSV file.

<TabItem label="Android" icon="mobile-android">

<Aside>
LastPass's Android app can't export. Use the browser extension or the LastPass website on a computer.
</Aside>

</TabItem>
<TabItem label="Browser extension" icon="puzzle">

LastPass says these steps work only in the browser extension. A Teams or Business admin can switch export off with a policy.

<Steps>

1. Click the grey or black **LastPass** icon in your browser toolbar.
2. Enter your email address and master password, then click **Log In**.
3. If multifactor authentication is on, complete it.
4. Click the **LastPass** icon again and open the **Account** tab.
5. Go to **Fix a problem yourself**, then **Export vault items**, then **Export data for use anywhere**.
6. If asked, enter your master password. You can tick **Do not re-prompt for** and pick a time to skip this later.
7. Click **Continue**. A CSV file downloads.
8. In LastPass for Safari the CSV opens in a new tab instead. Right-click the tab, choose **Save Page As...**, name the file and click **Save**.

</Steps>

Steps from [Export vault data from LastPass as a generic CSV file](https://community.lastpass.com/kb/articles/40-export-vault-data-from-lastpass-as-a-generic-csv-file%EF%BB%BF).

## Good to know

- The export leaves out attachments and the one-time code (TOTP) secrets stored in password items.
- Custom item types and custom fields are not supported by LastPass's CSV export.
- If the CSV comes out blank or LastPass emails you instead, use the website route.
- If you edit the CSV by hand, LastPass says to keep every column header in lowercase.

## Then, in WM Pass

Open Settings, Import, and choose the file. The [import steps](/guides/import-export/#importing-into-wm-pass) cover every WM Pass app.

Delete the export once WM Pass has read it.

If you exported on a computer and use WM Pass on your phone, import the file in WM Pass on that computer and [sync](/guides/backup-sync/), or copy the file to the phone over a USB cable. Email and cloud drives keep copies of what passes through them.
