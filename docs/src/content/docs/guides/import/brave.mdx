<Aside type="tip" title="Which file">
Brave saves your passwords as a CSV file in the same layout as Google Password Manager (name, url, username, password, note). WM Pass reads it as it reads that one.
</Aside>

<Tabs syncKey="device">
<TabItem label="Android" icon="mobile-android">
<Steps>

1. Open **Brave** and tap the **Main menu**.
2. Tap **Brave Password Manager**.
3. Tap the three-dot overflow menu at the top right.
4. Tap **Export passwords**. Brave saves a .csv file on the phone.

</Steps>

Steps from [How do I import or export data in Brave on Android?](https://support.brave.app/hc/en-us/articles/35780681703053-How-do-I-import-or-export-data-in-Brave-Android).

</TabItem>
<TabItem label="iPhone" icon="phone">

<Aside>
Brave's help page for logins and passwords on iOS lists no export. Export from Brave on a computer or an Android phone.
</Aside>

</TabItem>
<TabItem label="Computer" icon="laptop">
<Steps>

1. Open the Brave **Main Menu** at the top right and choose **Settings**.
2. Go to **Additional Settings**, then **Auto-fill**, then **Password Manager**.
3. Click **Settings** at the top left of the Passwords page.
4. Next to **Export Passwords**, click **Download file**.

</Steps>

Steps from [How do I use the built-in password manager?](https://support.brave.app/hc/en-us/articles/360018185951-How-do-I-use-the-built-in-password-manager).

</TabItem>
</Tabs>

## Good to know

- Brave's own help says anyone with access to the file can read it.
- On a computer you can also reach the page by typing `brave://password-manager/settings` in the address bar.

## Then, in WM Pass

Open Settings, Import, and choose the file. The [import steps](/guides/import-export/#importing-into-wm-pass) cover every WM Pass app.

Delete the export once WM Pass has read it.

If you exported on a computer and use WM Pass on your phone, import the file in WM Pass on that computer and [sync](/guides/backup-sync/), or copy the file to the phone over a USB cable. Email and cloud drives keep copies of what passes through them.
