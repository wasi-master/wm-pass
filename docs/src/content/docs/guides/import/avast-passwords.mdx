<Aside type="tip" title="Which file">
In Avast Passwords, export the plain **.csv** file with all your password data, not the Chrome or Firefox one. Avast's help pages name only CSV; WM Pass also reads a .json file from Avast Passwords if that is what yours writes.
</Aside>

<Tabs syncKey="device">
<TabItem label="Windows" icon="laptop">

This is the older Avast Passwords app inside Avast Antivirus. Avast has said it is ending support for it, so export while it still opens.

<Steps>

1. Open Avast Antivirus and go to **Privacy**, then **Passwords**.
2. If asked, unlock Passwords with your Master Password.
3. Open **Settings** at the top right.
4. Choose **Import / export data**.
5. Next to **Do you want to export passwords to a .csv file?**, click **Export**. Skip the Google Chrome and Firefox entries, which are written for those browsers.
6. Pick a place, name the file, and click **Save**.

</Steps>

Steps from [Exporting passwords from Avast Passwords](https://support.avast.com/en-au/article/273), with the choice of CSV from [Passwords - Settings](https://help.avast.com/en/av_abs/17/page_passwords_settings.html).

</TabItem>
<TabItem label="Browser extension" icon="puzzle">

This is the newer Avast Password Manager. Avast's article covers Windows and macOS, and the export is a CSV file.

<Steps>

1. Click the Avast Password Manager icon in your browser toolbar.
2. Click **Unlock vault**, or **Sign in** first if you are signed out, and unlock with One-Touch Login or your vault password.
3. Click the icon again and choose **Open Web App**.
4. In the left menu, click **Settings**.
5. Under **My data**, click **Export my vault data**.
6. In the pop-up, click **Export**. Enter your vault password if asked.

</Steps>

Steps from [Exporting Avast Password Manager data](https://support.avast.com/en-ca/article/2740).

</TabItem>
</Tabs>

## Good to know

- Avast says exporting Avast Passwords data is not supported on Mac, Android or iPhone. On those, sync your data to a Windows PC first, as Avast's article describes, then export there.
- Avast says a .csv file cannot be used to restore Avast Passwords.

## Then, in WM Pass

Open Settings, Import, and choose the file. The [import steps](/guides/import-export/#importing-into-wm-pass) cover every WM Pass app.

Delete the export once WM Pass has read it.

If you exported on a computer and use WM Pass on your phone, import the file in WM Pass on that computer and [sync](/guides/backup-sync/), or copy the file to the phone over a USB cable. Email and cloud drives keep copies of what passes through them.
