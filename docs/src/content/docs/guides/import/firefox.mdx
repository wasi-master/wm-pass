<TabItem label="Computer" icon="laptop">

These are the steps for Firefox 122 and later; older versions word the menu item as Export Logins.

<Steps>

1. Open the Firefox menu and choose **Passwords**. The saved-passwords page opens in a new tab.
2. Click the three-dot menu at the top right of that page, then **Export Passwords…**.

   <Shot src="https://assets-prod.sumo.prod.webservices.mozgcp.net/media/uploads/gallery/images/2026-09-17-10-55-46-49b9cc.png" alt="Firefox's saved passwords page with the three-dot menu open and Export Passwords highlighted" from="https://support.mozilla.org/en-US/kb/export-login-data-firefox" publisher="Mozilla Support" />

3. In the warning that the file will hold readable passwords, click **Continue with export**.

   <Shot src="https://assets-prod.sumo.prod.webservices.mozgcp.net/media/uploads/gallery/images/2024-01-22-15-28-44-889893.png" alt="Firefox's warning dialog before exporting passwords" from="https://support.mozilla.org/en-US/kb/export-login-data-firefox" publisher="Mozilla Support" />

4. If asked, enter your Primary Password or confirm with your computer's sign-in.
5. Choose a file name and place, then click **Save**. Firefox writes a .csv file.

</Steps>

Steps from [Export login data from Firefox](https://support.mozilla.org/en-US/kb/export-login-data-firefox).

</TabItem>

## Then, in WM Pass

Open Settings, Import, and choose the file. The [import steps](/guides/import-export/#importing-into-wm-pass) cover every WM Pass app.

Delete the export once WM Pass has read it.

If you exported on a computer and use WM Pass on your phone, import the file in WM Pass on that computer and [sync](/guides/backup-sync/), or copy the file to the phone over a USB cable. Email and cloud drives keep copies of what passes through them.
