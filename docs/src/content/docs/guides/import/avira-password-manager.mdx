Avira exports one format, a CSV file.

<Tabs syncKey="device">
<TabItem label="Web" icon="external">
<Steps>

1. Go to passwords.avira.com and log in to Avira Password Manager.
2. Click the **Settings** icon in the left-hand menu.
3. Scroll down to **MY DATA** and click **Export data**.
4. Click **Export CSV** to save the file.

</Steps>

Steps from [Export or import data from Avira Password Manager](https://support.avira.com/hc/en-us/articles/360000814057-Export-or-import-data-from-Avira-Password-Manager).

</TabItem>
</Tabs>

## Good to know

- Avira's help page gives export steps for the website only, at passwords.avira.com.
- Avira says the CSV is not encrypted.

## Then, in WM Pass

Open Settings, Import, and choose the file. The [import steps](/guides/import-export/#importing-into-wm-pass) cover every WM Pass app.

Delete the export once WM Pass has read it.

If you exported on a computer and use WM Pass on your phone, import the file in WM Pass on that computer and [sync](/guides/backup-sync/), or copy the file to the phone over a USB cable. Email and cloud drives keep copies of what passes through them.
