<Aside type="tip" title="Which file">
Export the codes to a **JSON** file. A plain file and a password-protected one both work; WM Pass asks for the password when you open a protected file.
</Aside>

Proton's help pages describe backups and imports but give no export steps, and they do not split the steps by device. The menu path below comes from the import help text in Aegis, which reads Proton Authenticator files.

<Steps>

1. Open Proton Authenticator.
2. Go to **Settings**, then **Export**.
3. If the app offers a password for the file, you can set one. Remember it, because WM Pass will ask for it.
4. Save the file somewhere you can pick it from inside WM Pass.

</Steps>

Steps from [Aegis's Proton Authenticator importer text](https://github.com/beemdevelopment/Aegis/blob/master/app/src/main/res/values/strings.xml).

## Good to know

- Proton Authenticator's automatic backups are a separate feature, under **Settings** and the **Security** section. Proton's page for them does not say whether they use the same file.
- A password-protected export is encrypted with a key made from that password, per Proton's description of its backups. Without the password the file cannot be opened.

## Then, in WM Pass

Open Settings, Import, and choose the file. If you set a password on the export, enter it when WM Pass asks. The [import steps](/guides/import-export/#importing-into-wm-pass) cover every WM Pass app.

Delete the export once WM Pass has read it. A plain export holds every secret key in readable form.
