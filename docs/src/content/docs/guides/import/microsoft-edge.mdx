<Aside type="tip" title="Which file">
Edge saves your passwords as a CSV file in the same layout as Google Password Manager (name, url, username, password, note). WM Pass reads it as it reads that one.
</Aside>

<TabItem label="Computer" icon="laptop">
<Steps>

1. Open **Microsoft Edge**.
2. Select **More** (the three dots), or press Alt + F, then select **Passwords**.
3. Select **More** again, then **Export passwords**.
4. Select **Export** to confirm.
5. Choose where to save the file.

</Steps>

Steps from [Export passwords in Microsoft Edge](https://support.microsoft.com/en-us/edge/export-passwords-in-microsoft-edge).

</TabItem>
</Tabs>

## Good to know

- Microsoft warns that anyone who can see the CSV can see the passwords in it.
- Exporting does not remove the passwords from Edge.

## Then, in WM Pass

Open Settings, Import, and choose the file. The [import steps](/guides/import-export/#importing-into-wm-pass) cover every WM Pass app.

Delete the export once WM Pass has read it. Microsoft suggests Shift + Delete so the file skips the Recycle Bin.

If you exported on a computer and use WM Pass on your phone, import the file in WM Pass on that computer and [sync](/guides/backup-sync/), or copy the file to the phone over a USB cable. Email and cloud drives keep copies of what passes through them.
