<Aside type="tip" title="Which file">
Export a 2FAS backup with no password. WM Pass reads only the unencrypted one.
</Aside>

<Tabs syncKey="device">
<TabItem label="Android" icon="mobile-android">
<Steps>

1. Open the 2FAS app.
2. Go to **Settings**, then **2FAS Backup**.
3. Tap **Export**.
4. Leave the password option off. WM Pass cannot read a backup that has a password.
5. Save the file on the phone, in a place you can pick it from inside WM Pass.

</Steps>

## Good to know

- 2FAS recommends a password for the backup file, but WM Pass reads the backup only without one.
- The app sends the file through "Export" (save) or a share button; either gives you a file WM Pass can open.

## Then, in WM Pass

Open Settings, Import, and choose the file. The [import steps](/guides/import-export/#importing-into-wm-pass) cover every WM Pass app.

Delete the export once WM Pass has read it.
