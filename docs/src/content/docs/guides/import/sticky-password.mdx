<Aside type="tip" title="Which file">
Choose **Sticky Password 6 XML**, the unencrypted XML export. WM Pass reads that file.
</Aside>

<Tabs syncKey="device">
<TabItem label="Windows" icon="laptop">

Sticky Password's own pages were blocked when this guide was written, so the steps come from other apps' import guides.

<Steps>

1. Open Sticky Password and log in.
2. Click **Menu** at the top right, then **Export**.
3. Choose **Export All**, or **Export only selected items**.
4. Pick the **Sticky Password 6 XML** format and click **Next**.
5. Name the file, pick a place, and click **Save**.

</Steps>

Steps from [Import from Sticky Password](https://docs.keeper.io/user-guides/import-records-1/import-from-sticky-password) and [How to Export from Sticky Password and Import into RoboForm](https://help.roboform.com/hc/en-us/articles/4422764975373-How-to-Export-from-Sticky-Password-and-Import-into-RoboForm).

</TabItem>
<TabItem label="Mac" icon="apple">

Third-party guides disagree about the Mac file. Enpass says the unencrypted export is an .xml or .txt file; RoboForm and NordPass say a .txt file. WM Pass needs the XML one, so if your Mac only offers .txt, export from Sticky Password on Windows.

<Steps>

1. Open Sticky Password and log in.
2. Open the **File** menu, then **Export**, then **Unencrypted**.
3. Name the file, pick a place, and save it.

</Steps>

Steps from [Import from Sticky Password](https://help.enpass.io/personal/latest/all/import-from-sticky-password).

</TabItem>
</Tabs>

## Good to know

- Sticky Password has help pages for exporting on Android and iPhone, but they could not be read, so no phone steps are given here. Export on a computer.
- Sticky Password cannot export passkeys.

## Then, in WM Pass

Open Settings, Import, and choose the file. The [import steps](/guides/import-export/#importing-into-wm-pass) cover every WM Pass app.

Delete the export once WM Pass has read it.

If you exported on a computer and use WM Pass on your phone, import the file in WM Pass on that computer and [sync](/guides/backup-sync/), or copy the file to the phone over a USB cable. Email and cloud drives keep copies of what passes through them.
