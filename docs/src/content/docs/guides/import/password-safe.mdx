<Aside type="tip" title="Which file">
Export to **XML**, from the Password Safe program documented at pwsafe.org.
</Aside>

<Tabs syncKey="device">
<TabItem label="Computer" icon="laptop">
<Steps>

1. Open Password Safe and unlock your database.
2. Choose **File**, then **Export To**.
3. Select **XML**. The export runs as a wizard.
4. If you only want some entries or fields, choose **Advanced field selection**. Title and Password cannot be turned off, because the XML format requires them.
5. Finish the wizard. Password Safe shows a report of what it did when it ends.

</Steps>

Steps from [Exporting Entries](https://pwsafe.org/help/pwsafeEN/html/export.html).

</TabItem>
</Tabs>

## Good to know

- Password Safe calls the XML file an unprotected copy of your data. Deleting it afterwards does not make it unrecoverable.
- The report can hold sensitive data. Password Safe lets you save it as a text file in the database folder, so delete it too.
- Bitwarden's guide describes a Password Safe 8 with different menus (Extras, then Export). Its steps are not covered here.
- To move one group or entry, right-click it and use **Export Group To** or **Export Entry To**.

## Then, in WM Pass

Open Settings, Import, and choose the file. The [import steps](/guides/import-export/#importing-into-wm-pass) cover every WM Pass app.

Delete the export once WM Pass has read it.

If you exported on a computer and use WM Pass on your phone, import the file in WM Pass on that computer and [sync](/guides/backup-sync/), or copy the file to the phone over a USB cable. Email and cloud drives keep copies of what passes through them.
