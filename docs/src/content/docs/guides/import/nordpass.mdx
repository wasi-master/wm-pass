<TabItem label="Computer" icon="laptop">

NordPass lists the Windows, macOS (Intel and Apple Silicon) and Linux desktop apps. The steps are the same in each.

<Steps>

1. Log in to NordPass.
2. Click the gear icon in the upper-left corner to open **Settings**.
3. Scroll to **Import and Export** and click **Export**.
4. Enter your master password and click **Continue**.
5. Save the CSV file to your device.

</Steps>

## Good to know

- On NordPass Business, an admin can restrict exporting with the Item exporting policy in the Admin Panel.

## Then, in WM Pass

Open Settings, Import, and choose the file. The [import steps](/guides/import-export/#importing-into-wm-pass) cover every WM Pass app.

Delete the export once WM Pass has read it.

If you exported on a computer and use WM Pass on your phone, import the file in WM Pass on that computer and [sync](/guides/backup-sync/), or copy the file to the phone over a USB cable. Email and cloud drives keep copies of what passes through them.
