---
title: WM Pass
description: A password manager that keeps its vault on your own devices, with no account and nothing sent anywhere unless you ask.
---

WM Pass keeps your passwords, one-time codes, cards, notes and SSH keys in an encrypted file on your own devices. There is no account to make, and it works with the network turned off. Every feature that uses a network starts switched off, and says what it sends before you turn it on.

It runs on Android, on macOS, Windows and Linux, in Chrome and Firefox, and on Wear OS. All of them share one Rust core, so a vault means the same thing everywhere.
